# Tabloom · 标签集

![Tabloom 图标](assets/icon-128.png)

用自己的 AI 模型，把散落的浏览器标签整理成主题；保存常用分组，一键回到工作空间。

Tabloom 使用 ES 模块架构，提供管理中心、快捷弹窗和原创图标，以 MIT 许可证开源，见 [LICENSE](LICENSE)。

## 功能

- **AI 用途整理**：将不同品牌的同类用途抽象到一个组，例如 ChatGPT、MiMo Studio 等对话页面统一归为 Chat，避免一个品牌一个组。
- **自定义模型**：自由填写 Chat Completions 兼容接口、模型名称、密钥和整理偏好，支持本地模型服务。
- **自动整理**：主动开启后整理新打开或跳转的未分组页面；连续标签事件合并处理。
- **固定工作空间**：保存当前分组，或手动创建网址清单；支持搜索、编辑、删除和一键打开。
- **固定组备份**：支持逐页编辑、清理重复网址，并以 JSON 导入或导出固定组。
- **自定义新标签页**：上方搜索或输入网址，下方展示固定组并一键打开；支持开关及 Bing、Google、DuckDuckGo 搜索引擎。
- **保护已有整理**：保留手动分组及固定标签页。固定组恢复后不受 AI 追加影响。
- **操作控制**：显示后台状态、支持停止整理；恢复固定组失败时回滚本次创建的页面。
- **可撤销整理**：工作台保留最近操作记录；当前浏览器会话内可撤销上次整理，已关闭、网址变化、重新分组或调整顺序的页面会跳过。
- **隐私排除**：设置网站域名后，该域名及其子域名不会进入模型请求或待整理数量。
- **模型用量**：工作台显示累计请求、接口返回的 Token 用量和近七天趋势；可手动填写服务单价查看本机估算。
- **数据迁移**：首次使用新版本时迁移之前保存的模型配置和固定组。

## 安装或升级

支持 Chrome 124 或更高版本，以及对应 Chromium 版本的 Microsoft Edge。Edge 中可以在 `edge://extensions/` 加载本项目。

1. 在 Chrome 打开 `chrome://extensions/`，开启开发者模式。
2. 点击“加载已解压的扩展程序”，选择本项目目录，无需构建。
3. 已加载旧版时点击该扩展的刷新按钮，并关闭旧的设置页面。
4. 点击扩展图标 → **设置**，连接模型后即可整理。

## 使用

### 连接模型

管理中心的 **设置 → 模型服务** 中填写接口地址、模型 ID 和可选的 API 密钥。

- 完整地址示例：`https://你的服务地址/v1/chat/completions`。
- 也可填写以 `/v1` 结尾的基础地址；只有主机的地址会补上 `/v1/chat/completions`。
- 支持 `http://localhost:端口/v1` 等本地服务。
- 其他非 Chat Completions 格式的接口需要通过兼容网关接入。
- 填写整理偏好，例如“按项目分组，研发资料与娱乐分开”。

保存后，在 **工作台** 点击 **开始整理**，手动操作立即执行。自动整理默认关闭，可在设置或工作台主动开启。自动整理默认等待 20 秒，支持在设置中调整为 5–300 秒；连续打开或加载未分组页面会重新计时，安静一段时间后合并请求。关闭标签不触发新分析，到请求前再次核对仍然打开的页面，短暂打开又关闭的页面不会发送给模型。每次网络请求最长等待 25 秒，大量标签按 60 个一批处理；浏览器休眠时调度可能延后。

自动整理只提交新增的未分组页面，并附带每个 AI 组最多两个页面作为用途参考。手动点击“开始整理”会重新分析未分组页面和当前会话中 AI 创建的组，方便将过细的品牌组合并为用途组。手动组、已保存为固定组的浏览器组、固定标签与内部页均保留。之前旧版生成的域名组会保留；想重新整理时，可以先解散，再点击开始整理。解散全部组会关闭自动整理，防止立即重新分组。

### 固定分组

- 工作台的浏览器分组卡片点击 **固定这组**，保存名称、颜色、网址与顺序。
- **固定分组** 页面可以手动新建、搜索、编辑和删除保存记录。
- 固定组支持逐页编辑标题、网址和顺序；可标记并一次移除重复网址。
- **导出** 会生成不含内部 ID 的 JSON 备份；**导入** 会作为新固定组追加，不覆盖现有记录。备份文件应按普通网址数据妥善保管。
- **一键打开** 在当前窗口新建整组页面，不会复用或关闭已经打开的页面。
- 保存记录独立于浏览器标签，关闭浏览器后仍保留。删除记录不会关闭已经打开的标签。
- 每组最多 300 个页面，只支持 HTTP/HTTPS 网址。

### 新标签页

重新加载扩展后，打开管理中心 → 设置 → **外观**，勾选“将 Tabloom 设为新标签页”，再点击“保存新标签页设置”。这个表单独立于模型服务设置，不需要先填写模型信息。

新标签页上方是搜索框，可搜索网页或输入完整网址、域名；下方展示已保存的固定组，可以一键打开。支持 Bing、Google、DuckDuckGo，默认使用 Bing。搜索词仅在提交后发往选定搜索引擎，不发送给 AI 模型。

开关默认关闭，关闭时保留浏览器原本的新标签页，不访问任何替代的内部地址。开启时，后台检测到 Chrome / Edge 原生新标签页后才导航到 Tabloom。设置里的“预览新标签页”可以在不开启接管的情况下查看效果。新设置对下次打开的新标签页生效；已经打开的页面保持原样。

### 数据去向

页面标题、网址路径、已有 AI 组名称及每组最多两个代表页面、整理偏好发送至你配置的接口。默认不发送网址查询参数，始终移除网址片段；可以在设置中开启发送查询参数。页面标题或路径自身仍可能包含敏感信息。

密钥和固定组存于本机扩展存储，不通过 Chrome 同步。使用可信服务；模型调用可能产生该服务的费用。

在设置的 **隐私与数据** 中填写排除域名，例如 `bank.example.com`。填写 `example.com` 会同时排除它的子域名；被排除页面不会发送给模型。

整理记录仅保存时间、操作结果和数量。为支持撤销，扩展会在本机当前浏览器会话中临时保存被移动页面的网址、原分组和顺序；窗口关闭后删除快照，不会把快照发送给模型。关闭浏览器后记录仍可查看，但旧会话的页面快照不再提供撤销。

工作台的费用估算默认关闭。可填写服务提供方给出的输入、输出单价；估算只根据接口返回并记录的 Token 计算，不读取或推测服务账单。

## 开发与验证

原生 JavaScript ES 模块，没有构建依赖。模块说明见 [ARCHITECTURE](ARCHITECTURE.md)。

使用 Node.js 22 或更高版本，在 PowerShell 中运行：

```powershell
npm test
npm run check
```

GitHub Actions 会在推送、Pull Request 和手动触发时运行这两项检查。

可选浏览器验证需要 Playwright 与 Chromium。安装在本机的 Playwright 可直接使用：

```powershell
node scripts/browser-check.js
```

也可以通过环境变量指定已经安装的运行时：

```powershell
$env:TABLOOM_PLAYWRIGHT_MODULE = '你的路径/playwright/index.mjs'
$env:TABLOOM_CHROMIUM = '你的路径/chrome.exe'
node scripts/browser-check.js
```

浏览器验证使用隔离配置和本地模拟模型服务，不读取你日常浏览器的数据，不访问真实模型。验证包含配置、分组、固定保存、编辑、恢复、自动整理与响应式界面，截图输出到 `artifacts/`。
